データについて
地震一覧はP2P地震情報 JSON API v2を利用します。気象・津波の各タイルは気象庁の公式ページへ移動します。情報の遅延・欠落・通信障害があり得ます。
このアプリは補助的な閲覧ツールであり、緊急地震速報や災害警報の受信・通知を保証しません。避難等の判断は自治体・気象庁・消防などの公式情報を優先してください。
